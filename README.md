# portfolio-react

A modular React portfolio for Arafath H, built to replace the original static HTML resume page with a more maintainable component-based structure.

## Tech stack

- React + Vite
- CSS modules / custom CSS
- No backend required for the initial version

## Getting started

```bash
npm install
npm run dev -- --host
```

Then open the local URL shown by Vite in your browser.

## Production build

```bash
npm run build
```
